# 🛍️ TechMart – Modern E-Commerce Website

TechMart is a modern, responsive e-commerce website built to showcase the latest technology products, including smartphones, cameras, gaming consoles, smartwatches, speakers, and headphones. It provides a clean and user-friendly shopping interface for exploring technology products.

## ✨ Features

- **Modern UI:** Clean and visually appealing interface for browsing technology products.
- **Responsive Design:** Layout adapted for desktop, tablet, and mobile screens.
- **Product Showcase:** Explore different categories of modern technology products.
- **Reusable Components:** Organized React components for easier maintenance and development.
- **Interactive Interface:** React hooks for managing component state and user interactions.
- **Tailwind CSS:** Utility-first styling for a consistent and responsive design.
- **DaisyUI:** Prebuilt UI components for faster interface development.

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Styling:** Tailwind CSS, DaisyUI
- **Build Tool:** Vite
- **Deployment:** Vercel
- **Version Control:** Git and GitHub

## 🚀 Getting Started

Follow these steps to run TechMart locally.

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YashSinghal02/TechMart.git
   ```

2. Navigate to the project directory:

   ```bash
   cd TechMart
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.
